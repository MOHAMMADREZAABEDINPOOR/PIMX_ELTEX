# 🌟 Aetheria: Sky Isles Adventure

A complete 3D platformer browser game inspired by classic side-scrolling platformers, set in an original fantasy sky world.

## 🚀 How to Play Immediately
Simply open **`index.html`** in any modern web browser (Chrome, Edge, Firefox, Safari).
No installation, no npm, no build tools required!

## 🕹️ Controls
- **Run Left / Right**: `A` / `D` or `◀` / `▶` Left / Right Arrow keys
- **Jump**: `Space`, `W`, or `▲` Up Arrow key
- **Double Jump**: `Space` while airborne (with Celestial Wings power-up 🪶)
- **Stomp Attack**: Jump onto enemies from above
- **Pause**: `Escape` or `P`
- **Mobile / Touch**: On-screen virtual buttons `◀`, `▶`, and `⤒ JUMP`
- **Gamepad**: Standard controller support (Left Stick / D-pad to move, `A` / `✕` to jump)

## ✨ Game Features
- **Original Fantasy World**: Floating grassy sky isles, crystal caverns, and majestic clouds.
- **Pip the Star Sprite**: Procedurally animated 3D character with squash & stretch, running strides, and blinking eyes.
- **Moving Platforms**: Floating crystal slabs and vertical elevators.
- **Crumbling Platforms**: Fragile bridge tiles that wobble and fall after being stepped on.
- **Spring Mushrooms**: Bouncy pads that launch Pip high into the sky.
- **Collectibles**: Faceted star gems with ascending combo chimes, plus 3 hidden Celestial Relics.
- **Power-Ups**: Celestial Wings (super jump & double jump), Swift Berry (super speed), and Star Shield (invulnerability).
- **Enemies with AI**: Hopping Puff Slimes, Horned Beetles, and Floating Wisps.
- **Traps & Hazards**: Crystal spike beds and swinging spiked pendulums.
- **Checkpoints**: Radiant altars that ignite when approached to save your respawn point.
- **Health & Lives**: 3 animated heart containers and 3 lives system.
- **Celestial Goal Flag**: Hoist the golden banner at the Citadel gate with fireworks and confetti celebration!
- **100% Synthesized Audio**: Built-in procedural Web Audio API sound effects and background music with mute controls.
